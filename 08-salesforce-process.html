Any of the 6 routes can apply, including full price and discount sales.

1. Did the customer receive the item?

  • No, it never arrived → Sale at 0 cost (no return label, Complimentary Shipping)
  • Yes, but it's faulty and we replace it free → Accommodation (return location + return label)
  • Yes, and they just want to buy something → Sales order

2. Is it a machine or a spare part?

  • Machines can be replaced free (Accommodation) or re-sent at 0 cost
  • Machines are never sold at full price - full price and discounted sales are for spare parts and accessories only

Known contradiction - flag for your trainer A later cancellations note says "we cannot make a sale at full price" at all on machines, because customers must order machines from the site - while §7 above frames "full price" as an existing route for spare parts. Both sources agree machines are never sold at full price; the disagreement is only about whether "full price" exists as a route label at all. Check with your trainer which wording your team follows.

Groundwork, Before Any Route

Every route on this page assumes these three things already exist in Salesforce, built in this order: an Account, a Registered Product (Asset), and a Case. Do not skip a field - an incomplete case is what Task Force bounces back to you later. Full step-by-step below.

  1. Create the Account

    The customer's record in Salesforce. Fill in every field below before moving on:

    • First name and Last name
    • Telephone number, always with country code (e.g. +49123456789)
    • Email address
    • Language preference
    • Full shipping address
    • Account currency
    Why this matters Wrong Language preference means the customer gets notifications in the wrong language. Account currency must match the country.

    Confirm spelling using the phonetic alphabet for the name, email, and address before saving.

  2. Create or Update the Registered Product (Asset)

    The specific machine or part the customer owns. If one already exists for this customer and model, update it instead of creating a duplicate.

    • Asset name = customer's name + product model number
    • Product = model number from the website
    • Purchase date, according to the proof of purchase
    • Batch code - if not available, put 1111
    • Serial number - if not available, leave empty
    Don't block on missing data No proof of purchase yet? Use 1111 for Batch code and leave Serial number blank rather than guessing.
  3. Create the Case - Case Details

    Open the case and fill in every field in this section first:

    • Inquiry Type
    • Status (usually automatic, e.g. "Waiting on consumer")
    • Waiting Reason (usually automatic)
    • Case currency (must match the country)
    • Country
    • Language - never plain "English"; choose Country(English) or Ireland(English)
  4. Fill in Product Info (on the case)

    This links the case to the machine and where it was bought:

    • Product = model number from the website
    • Brand = Sage
    • Batch Code = the 4 numbers after the letter in the serial number
    • Serial number
    • Purchase from
    • Purchase date
    • Order - only if the machine was purchased from Sage Appliances
    • Link the asset - update the existing one from Step 2, or create one
  5. Fill in Description Information

    This is what the repair centre and any teammate who picks up the case afterward actually reads:

    • Complaint code = the correct code for the issue with the unit
    • Sub complaint
    • Subject = what the issue is, in writing
    • Description = detailed, updated after every interaction
    Description is not optional detail This field is what the repair centre reads as their instructions.
  6. Finish: Vital Signs, Email, Case Comment

    Every case ends the same three-part way:

    • Complete the Vital Signs
    • Send email to the customer
    • Case comment, in English - mention everything: the issue, what you did, what you advised
    Never forget Case comments stay private. Never toggle Public on.

The Six Order Routes

Every route below starts with the groundwork above already done.

Accommodation - replacing a machine
  1. Select return location in Case Details: Windhorn Domestic = Germany · Windhorn Intl = other countries · Perfetto Return Center = UAE
  2. Create return label
  3. Create accommodation, press NEW ORDER
  4. Select the shipping method
  5. Activate the order
  6. Send quote
  7. Send email to customer: 036A = Accommodation with SIA · 036B = Accommodation without SIA
  8. Case comment
Accommodation - replacing spare parts and accessories
  1. Create accommodation, press NEW ORDER
  2. Select the shipping method
  3. Activate the order
  4. Send email to customer, Order confirmation template
  5. Case comment

Shorter than the machine version - no return location, no return label.

Sale at 0 cost - spare parts and accessories
  1. Create new case, Inquiry type: Order issue
  2. Product details complete - fill Original PO with the order number, and also in Order
  3. Complaint code: Order issue
  4. Sub complaint
  5. Description
  6. Create Sale with 0 cost, press NEW ORDER
  7. Select the shipping method
  8. Select Complimentary Shipping
  9. Activate the order
  10. Email the customer, Order confirmation template
  11. Case comment
Sale at 0 cost - finished goods and machines

Same start as spare parts, but the middle has the non-receipt form and an escalation.

  1. Create new case, Inquiry type: Order issue
  2. Product details complete - Original PO with order number, and also in Order
  3. Complaint code: Order issue
  4. Sub complaint
  5. Description
  6. Send email with template 103-DPD Declaration of Non-Receipt
  7. Case comment
  8. Wait until you receive the filled and signed form
  9. Escalate to > ORDER
  10. Email customer, Pre-escalation template
  11. Case comment
  12. Wait for feedback from ORDER
  13. Create Sale with 0 cost, press NEW ORDER
  14. Select the shipping method
  15. Select Complimentary Shipping
  16. Activate the order
  17. Email the customer, Order confirmation template
  18. Case comment
Sales at full price (spare parts & accessories only)
  1. Create the Order, press NEW ORDER
  2. Select the shipping method
  3. Send Quote
  4. Activate is not needed
  5. Email the customer, Order confirmation template
  6. Case comment
Sales with discount
  1. Create the Order by manually entering the discounted price, press NEW ORDER
  2. Select the shipping method
  3. Send Quote
  4. Activate is not needed
  5. Email the customer, Order confirmation template
  6. Case comment

Only difference from full price: you type the discounted price in yourself.

Patterns Worth Memorising

  • Every route ends with email the customer, then case comment
  • Every order starts with NEW ORDER
  • After NEW ORDER it's always shipping method next
  • Activate the order on accommodations and 0-cost sales. Not needed on full price and discounted sales
  • Send Quote on the sales routes and on machine accommodation. Not on the two shorter free routes
  • Complimentary Shipping only appears on Sale at 0 cost
  • Return label and return location only appear on the machine accommodation

Cancellations

All cancellations are handled by Task Force.

  1. Escalate to Misc queue
  2. In Comments write: Cancellation Request

Conditions: applies to any order with a status that is not Shipped. If already Shipped and the customer wants to cancel, do not escalate to Misc - instead ask how they want to proceed, offer an RMA refund whenever possible, and advise accepting delivery + using the return label for a faster refund (avoids depot delays).

"Order generated" status means it's ready to ship.

Backorder & Stock

  • Check the machine is available before creating the order - if not, Sage will cancel it
  • Explain the situation and point the customer to the "Notify Me" button
  • Tier 2 can be asked to notify us when restocked
  • To check stock: left menu → Products → search the model number. BDE/AE only
  • Never tell a customer the exact stock amount
  • Out of stock on the site but showing stock in Salesforce still counts as out of stock - that stock is reserved for replacements
  • If the customer won't wait, offer a repair instead

ScreenMeet

Use it as often as possible. Send the invite link by email using the ScreenMeet template. Works fine on Android - on iOS it only works in Chrome. The customer cannot see us.

Refunds

Automatic refunds (Refund button)

Conditions: case completely filled in and correct · bought from us within 30 days of the order, for the whole order · create a separate case for each item · no refund without a return location.

Machines/appliances: customer must return it (gets a return label). Accessories: customer keeps the old/defective one, DIF ticked (Destroy In Field).

  1. Complaint code: Final Return (Refund)
  2. Click Refund
  3. Select the item according to the order
  4. Click Submit
  5. Send the email
  6. Case comment

Manual refunds (escalation)

Escalate when the refund can't be processed automatically via RMA, or you can't provide a return label.

  1. Escalate to Misc queue
  2. In Comments write: Refund Request, EUR XX (exact amount)
  3. Include: Order number; whether it's a whole-order or partial refund (name the product/SKU if partial)

If details are missing, Task Force sends the case back to complete. Open a case for each item, even for a full-order refund.

Full refund, building the case (B2C RMA)

B2C RMA is the refund for a machine bought from the website.

  1. Inquiry Type: Support & Service
  2. Product: model number from the website
  3. Brand: Sage
  4. Batch Code: the 4 numbers after the letter in the serial number
  5. Serial number, Purchase from, Purchase date
  6. Website order or Salesforce order number in Original PO# and in Order
  7. Order: only if purchased from Sage Appliances
  8. Complaint code and Sub complaint code: Final Return
  9. Select the relevant Return location
  10. Send the Return Label
  11. Select REFUND

Complaint Info on screen: Complaint Code = Final Return (Refund) · Sub Complaint Code = Buyer's remorse / other · Secondary Sub Complaint Code = left blank.

For spare parts/accessories: EMEA SOP > Accounting & Finance > Refund: B2CRMA > Spare Parts & Accessories - same idea, DIF means the customer keeps the item.

The Refund flow screen

  1. Select the item to refund via the radio button in the ACTION column (multiple items all appear here)
  2. Leave DIF alone - it ticks itself on spare parts (Destroy In Field, we don't need it back)
  3. Click Submit once, after the selection is done

Columns: ACTION, PRODUCT, PRODUCT NAME, PRODUCT TYPE, DIF, EXTENDED WARRANTY, RETURN ONLY EXTENDED WARRANTY.

The shipping cost trap If the Order Grand Total is 40 EUR or less and you're refunding it fully: check the order before applying any refund. If Financial Information shows shipping costs, do not use the automatic refund - use the manual refund process instead, and write in your case comment why. Example note to Task Force: "Full refund needed for order [number], shipping costs included so a manual refund is required, automated refund should not be used."

VAT Invoice Requests

  • Complaint code: Registration & Promotion
  • Sub complaint: Proof of purchase
  • Escalate To: Refund & Billing Queue
  • Escalation Reason: Invoice Request
  • Escalation Notes: ask the team to send the VAT invoice/invoice, with order number and business unit
  • Status: Waiting Internal · Priority: Low · then Next

SIA - Shipping In Advance

Only when the customer asks for a shipment in advance. We hold a small deposit so we can ship the new item before we get the faulty one back - the customer gets packaging to return the faulty unit safely.

  • The deposit is only authorised, never charged
  • Voided once the faulty item is delivered back to our warehouse
  • Voids automatically if returned within 20 days of receiving the new unit
  • If not delivered back within 20 days, the SIA is charged

Steps after following the accommodation process, if the customer asks for SIA: (1) inform the customer of the service fee, (2) send quote. The fee amount is in the accommodation order, under Financial Information as the CC Authorization Amount.

Escalations

General Escalate screen

Case tabs, left to right: Details, Case Comments, Feed, Related, ScreenMeet, Escalate, Activity, Quick Links, Communications.

Escalate tab flow: Escalate To → Escalation Reason (required) → Escalation Notes (255 character limit) → Status (usually Waiting Internal) → Priority → Next.

For a manual refund: Escalate To: Misc, Reason: Other, note carries web order, SF order, amount, and country.

Escalation to Tier 2 (two parts - don't forget the second)

First: escalate normally on the Escalate tab (in training, use the case comment).

Second: go into Feed, refresh, find your escalation, and comment on it with this template:

Unit model specifications:
POP (Y/N):
Previous case (Y/N):
Current situation:
Customer's expectations:
Other info:
  • Escalation reasons in use: replacement, order issue, refund, MR, Warranty Approval, TBS advice, tracking info
  • Unit model specifications: model number, whether it's RM, whether it's second-hand
  • Previous case: if yes, include the case number
  • Current situation: the issue, the troubleshooting (TBS) performed, and any solutions offered
  • Other info: repeat failure Y/N, why there's no proof of purchase if there isn't one, anything else relevant

Non-Activated Orders

Task Force cleans these up because of daily loads of incorrect orders - either missing a product or never activated.

  • All Accommodation orders must be activated, even if SIA was already sent
  • If you forgot the SKU or closed the order while working on it, continue on the same order from the customer's account
  • Do not create unnecessary orders

What Task Force does: deletes orders missing a product; sends the rest back to you to check whether activation is needed (Task Force will not activate orders - that's your job).

Where the Buttons Are / Case Status Path

Case record toolbar: New Order, Send Promo Code, Refund sit together on one row; Reset Password, Delete, New Order sit on the row above; Mark Status as Complete is the blue button. Refund is two along from New Order - Warranty Approval sits in the same dropdown, under it.

Right-hand panel: Inquiry Complaint Code Editor (Inquiry Type, then Complaint Code and Sub Complaint Code side by side, then Save), then Recent Orders, Work Orders, and Registered Products (Assets).

Case status path: Waiting on consumer → Waiting internal → Response Received → Inventory OOS → Closed.
